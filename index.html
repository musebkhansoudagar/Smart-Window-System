Welcome to my project!

project title

A Smart Window System is an automated solution designed to open or close windows based on environmental conditions. Utilizing sensors like rain detectors, temperature/humidity sensors (DHT11), gas sensors (MQ-5), and motion detectors (IR), the system responds intelligently to ensure indoor comfort and safety. Controlled by an Arduino Mega, the setup uses a DC motor and relay module to drive the mechanical movement of the window. This project aims to enhance energy efficiency, reduce manual effort, and protect indoor spaces from adverse weather and pollution.

Problem Statement

Most traditional windows operate manually, requiring people to open and close them by hand. This lack of automatic control is inconvenient, especially in modern smart homes or buildings that aim for automation and ease of use. Additionally, these windows do not have built-in safety features to detect environmental hazards such as gas leaks or rain. As a result, if a window remains open during such conditions, it can pose serious risks to both people and property. Moreover, manual operation often leads to improper ventilation—either too much or too little airflow—which forces cooling or heating systems to work harder. This not only reduces energy efficiency but also leads to higher electricity consumption and increased utility bills.

Literature review

From the literature, we found that some smart systems use sensors like light, rain, or motion to detect changes in the environment. Gas sensors are also used in homes for safety. A few systems can even close windows when it starts raining. However, most of these systems only focus on one task, like sensing rain or gas, and do not fully control the window based on different conditions. Very few systems use both sensors and motors together to make windows open or close automatically. From this, we learned that using multiple sensors like gas, rain, and motion together, along with a motor, can make windows smarter. This can help create a low-cost smart window system that works well in homes and buildings.

Rack and Pinion Mechanism in Smart Window System – Brief Overview:

> The rack and pinion mechanism is used in smart window systems to automatically open and close windows. It converts the rotational motion of a DC motor (pinion gear) into linear motion of a straight gear (rack).

Pinion:

A small circular gear attached to the motor shaft.

Rack:

A straight gear that moves horizontally when the pinion rotates.

When the motor turns the pinion: The rack moves forward or backward, sliding the window open or closed. The direction of motor rotation controls whether the window opens or shuts.

Benefits:

Precise control over window position. Smooth linear movement. Compact and efficient for smart automation.

CODE :


#include
#define switch1 A0
#define switch2 A1
#define smokePin A2
#define rainPin A3
#define motorIN1 3
#define motorIN2 4
#define dhtPin 2
#define DHTTYPE DHT11
DHT dht(dhtPin, DHTTYPE);
void setup() {
pinMode(switch1, INPUT_PULLUP);
pinMode(switch2, INPUT_PULLUP);
pinMode(motorIN1, OUTPUT);
pinMode(motorIN2, OUTPUT);
Serial.begin(9600);
dht.begin();
}
void loop() {
float temp = dht.readTemperature();
int smoke = analogRead(smokePin);
int rain = analogRead(rainPin);
Serial.print("Temp: "); Serial.print(temp);
Serial.print(" | Smoke: "); Serial.print(smoke);
Serial.print(" | Rain: "); Serial.println(rain);
if (smoke > 600 || temp > 38) {
// Rotate clockwise until switch1 is pressed
digitalWrite(motorIN1, HIGH);
digitalWrite(motorIN2, LOW);
while (digitalRead(switch1) == HIGH) {
// Keep rotating clockwise
delay(100); // prevent CPU overuse
}
stopMotor();
}
if (rain < 700) {
// Rotate anticlockwise until switch2 is pressed
digitalWrite(motorIN1, LOW);
digitalWrite(motorIN2, HIGH);
while (digitalRead(switch2) == HIGH) {
// Keep rotating anticlockwise
delay(100); // prevent CPU overuse
}
stopMotor();
}
delay(500); // avoid spamming Serial Monitor
}
void stopMotor() {
digitalWrite(motorIN1, LOW);
digitalWrite(motorIN2, LOW);
}
